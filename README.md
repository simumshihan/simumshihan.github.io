# Shihan — GIS Portfolio

A responsive personal portfolio website for GIS, remote sensing, environmental analysis and disaster-risk projects.

## Files
- `index.html` — website structure and content
- `style.css` — visual design and responsive layout

## How to publish with GitHub Pages
1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload `index.html` and `style.css`.
3. In GitHub: **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main`, and save.
5. Your site will be available at `https://YOURUSERNAME.github.io/`.

## Before publishing
Replace:
- `your.email@example.com`
- LinkedIn URL
- GitHub URL
- Project placeholder blocks with your actual map images
- Project `href="#"` links with detailed project pages or repositories
- Education details with your final wording
